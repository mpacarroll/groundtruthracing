# Ground Truth Racing

Everyone watches the cars. We watch the tyres.

The public site for @groundtruthracing: the Race Weekend Brief before every race, the prediction log graded in public, and the season's Tyre Report.

Every number is measured from public timing and telemetry (TracingInsights, Jolpica, OpenF1). Nothing is simulated. Not affiliated with Formula 1, the FIA or any team.

This repository is generated. Pages here are rebuilt and replaced on each publish, so edits made directly here are overwritten.
